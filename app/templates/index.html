Why PCA Features?

Original features are confidential. PCA preserves patterns while protecting cardholder privacy.

About This Project

🎯 Objective

Build an ML system to detect fraudulent credit card transactions with high precision and recall using ensemble methods.

⚖️ Challenge

Extreme class imbalance (0.17% fraud). Accuracy alone is misleading — we optimize F1 Score and ROC-AUC.

🛠 Solution

SMOTE balancing + RandomizedSearchCV tuning + Random Forest achieving 98.2% F1 and 99.7% AUC.
